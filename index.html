为什么选择燧石启动器？

从底层网络打洞到像素级 UI 打磨，把「装游戏、修崩溃、管 Mod、调 HUD、联机」收进同一个界面。

硬核 P2P 联机与快捷组网

自研 UDP 打洞与 STUN NAT 行为判定，无需公网服务器。更有「服务器快捷加入」功能：复用运行中实例，通过 /connect 指令与窗口置顶直接拉人。支持断链检测、不换码重连，打洞失败智能降级。

STUN / UDP 打洞/connect 快捷加入断线不换码

不死鸟级 HUD 与多开管理

独立窗口实时显示 FPS / 内存 / CPU。独有「1s 定时自愈重绑」与跨进程扫描偏移修正，游戏进程退出或丢失瞬间自动找回。支持多开挂机，多开时绝不提前释放游戏进程，后台稳如泰山。

HUD 自愈重绑多开进程锁定跨进程抓取

黑匣子崩溃自愈

自动识别异常，非破坏性修复内存与缺失库。异常时能提取聊天记录，导出为染色 TXT/MD 报告。

聊天记录导出染色报告

“老中医”级 Java 兼容

彻底解决旧版 Forge 与原版的崩溃噩梦。自动识别高版本拦截，精准静默下载 Java 8。修复 inheritsFrom 前置缺失导致的退出码 1。

Java 8/21 自动匹配前置补全

发烧级音乐引擎

聚合六大音源。自带专业 LRC 引擎（二分查找 + 时间偏移修正）。进游戏自动调低音量，剔除所有反人类交互。

歌词精准对齐音量联动

四套独立 UI 语言
